## 2. 已修复的缺陷与教训

### P0 构建静默丢内容（2026-09-02）

- 现象：12 条 prompt 全部移入分类子目录后，构建输出 `0 prompts` 且退出码为 0。
- 根因：只采集顶层 `*.md`，目录变成分类后顶层没有文件。
- 修复：递归采集；ID 改为相对分类根目录的路径；分类目录为空时报错。
- 教训：**「0 条」不一定是合法结果**。校验要覆盖「有目录但没有内容」这种情况。

### P0 瀑布流卡片全堆第一列（2026-09-04，曾已上线）

- 现象：DOM 结构、列数、卡片数全对，只是所有卡片都在第一列。
- 根因：`renderMasonry` 在 section 挂进文档之前被调用。脱离文档的元素没有布局盒，
  `offsetHeight` 恒为 0，「放进最短列」每轮都选中第 0 列。
- 修复：先挂载再测量；折叠时不建瀑布流，展开时补建。
- 教训：**依赖测量值的代码，前提比逻辑更容易坏**。`offsetHeight` 的两条浏览器契约
  （必须已挂载、不能被隐藏）已固化进 `tests/dom_stub.js`。

### P1 分组配色对比度不足（2026-09-04）

- 缺陷：同一个 `--group-accent` 同时用于装饰和文字，浅色主题 4 个色相低至 2.25:1。
- 修复：拆成 `--group-accent`（装饰）与 `--group-accent-text`（文字），明度分两档。
- 教训：同一个颜色值不可能同时满足装饰与正文的对比度要求。

### P1 弹窗逻辑零测试覆盖（2026-09-13）

- 缺陷：DOM 桩注册了弹窗 id，却从未点击过卡片，`openModal()` 一次都没执行过。
- 修复：覆盖 prompt、有正文有链接、有正文无链接、无正文四类组合；补齐桩的 `contains`。
- 教训：**「注册了 id」不等于「测过」**；测试要走到分支，而不是只看元素存在。

### 分类按钮点击无反应（2026-09-08）

- 现象：点击末尾分类，页面不动、高亮不变。
- 根因：文档末尾没有滚动余量，`scrollTo` 被钳制；高亮兜底又把结果写死成最后一组。
- 修复：按缺口补 `padding-bottom`；点击时强制指定高亮；判定加 1px 亚像素容差；
  窄屏把高亮 chip 横向带回可视区。
- 教训：滚动位置是有物理上限的，不能假设「想滚到哪就滚到哪」。

## 3. 维持现状的取舍

| 取舍 | 理由 | 重新评估的条件 |
| --- | --- | --- |
| `marked` 结果直接写入 `innerHTML`，不消毒 | 内容全部来自本人仓库；引入消毒器会打破零依赖 | 开始接受他人投稿或抓取外部内容时 |
| 瀑布流每插一张卡读一次 `offsetHeight` | 当前规模无感；改成批量测量会增加复杂度 | 单次展示超过数百条时 |
| 分组色板固定 8 色 | 当前分类数少于色板容量；色相稳定、实现简单 | 分类长期超过 8 个时 |
| 内容 ID 全局唯一（含 prompts 与 skills） | 当前无同名冲突；保持校验简单 | 需要在两类内容中使用同一路径名时 |
| 不做搜索、不做单条深链 | 规模小，需求未要求；先保证取用路径短 | 内容超过 50–100 条，或需要引用单条内容时 |
| 发布延迟最长约 5 分钟 | 个人使用可接受；静态站无需实时 | 编辑后需要立即看到线上效果时 |
| skill 展示副本与运行时 skill 独立演进 | 站内只是浏览与复制，不参与 agent 加载 | 需要站内副本跟随上游自动更新时 |
